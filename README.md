# Crypt.NET
CryptNET by MR.Sa6oR is a multi-algorithm encryption tool built with .NET. It supports AES, DES, 3DES, RC2, Rijndael, RSA, MD5, SHA1, SHA256, SHA512, HMAC, and Base64. Users can encrypt text and files, generate hashes, and verify data. It combines professional-grade cryptography with an easy-to-use design for both beginners and security enthusiasts
